# Triage 标签

相关 Skill 使用五个规范 triage 角色。本文件把角色映射到本仓库 issue tracker 中实际使用的字符串；本地 Markdown tracker 把这串字符串写在工单文件的 `Status:` 行。

| mattpocock/skills 中的标签 | 本仓库的标签      | 含义                                 |
| -------------------------- | ----------------- | ------------------------------------ |
| `needs-triage`             | `needs-triage`    | 维护者需要评估该 issue               |
| `needs-info`               | `needs-info`      | 等待报告者补充信息                   |
| `ready-for-agent`          | `ready-for-agent` | 规格完整，可交给 AFK Agent           |
| `ready-for-human`          | `ready-for-human` | 需要人来实现                         |
| `wontfix`                  | `wontfix`         | 不会处理                             |

Skill 提到某个角色时（例如“应用 AFK-ready triage 标签”），使用表中对应的字符串。如需调整实际使用的词汇，修改“本仓库的标签”一列。
