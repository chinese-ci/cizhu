# ADR 0002：不透明 source_id 与生产者侧策展

- 状态：已接受
- 日期：2026-11-21

## 背景

来源语料最初携带平台名、词库 ID、标题、描述与来源类目。这些字段会把平台知识带进[词修 CiXiu](https://github.com/chinese-ci/cixiu) 与公开侧，也让“增量来源”可能改变展示形、类目与顺序。

## 决策

1. 来源语料只含 `source_id`、`order`、`categories`（物料类目候选）与 words。
2. `source_id` 不透明、稳定；真实来源上下文由生产者私有映射表保存。
3. 词库级筛选、来源类目到物料类目的映射、删除词条与改类目全部在来源层完成。
4. 增量来源默认是“只追加新词”；生产者负责在导出前过滤已存在的词。
5. [词修 CiXiu](https://github.com/chinese-ci/cixiu) 不解析平台格式，也不知道平台概念。

## 后果

- 词修 CiXiu 与公开契约完全去平台化；报告用 `source_id` 关联。
- BYO 生产者承担类目映射与筛选责任；物料类目公开且数量有限，成本可控。
- 删除/改类目不可通过追加来源表达，需要来源层的策展覆盖与审计。

## 备选

- 保留标题/描述并脱敏：会改变库级过滤结果，且脱敏规则难维护。
- 词修 CiXiu 支持 override：把清洗工具扩成策展工具，契约面增大。
