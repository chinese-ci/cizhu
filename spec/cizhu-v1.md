# 词铸 CiZhu v1 产品规格

## 问题

中文五笔 86 用户依赖的官方方案把字表与词表绑在一个大码表里：字表几乎不变，却难以按领域扩展词、按类目维护、由社区分工贡献。来源词条数量大、质量参差，混有句子、符号、异体字；人工整理不可复现，也容易把来源信息带进公开产物。

## 目标

1. 建立可复现的管道：来源语料 → 清洗 → 纯词库物料 → 输入法产物。
2. 物料结构、顺序与逐字节结果稳定；同一输入重复运行结果一致。
3. 公开侧不出现来源名称、地址、平台类目或原始文件。
4. 默认交付与官方同名、可 drop-in 的 [Rime](https://github.com/rime/rime) 五笔 86 三 schema 方案包。
5. 明确扩展点：BYO 语料、target 适配器、物料与类目契约。

## 用户与场景

- **维护者**：从私有来源层产出全量语料，运行清洗与构建，发布物料与默认方案包。
- **贡献者**：提供来源提案、物料修正、契约或工具 PR、新的 target 适配器。
- **自带语料者**：用自己的文本或更小范围语料运行[词修 CiXiu](https://github.com/chinese-ci/cixiu)，得到稳定物料；可用[词合 CiHe](https://github.com/chinese-ci/cihe) 构建默认目标或裁剪类目。

## 管道

### 来源层（私有）

- 枚举来源、下载、解析、库级筛选。
- 映射物料类目候选。
- 分配稳定 `source_id`，私下保存关联表。
- 输出来源语料契约。

### 词修 CiXiu

- 读取 `source_id`、`order`、`categories`、words。
- 条级清洗、字形归一、去重、类目候选裁决。
- 输出 73 个物料文件、私有清洗报告与逐条字形事件。
- 不处理删除词条或整库排除。

### 词合 CiHe

- 读取物料，按 target 适配器编码并生成 Ci 内容片段。
- 默认 target `rime-wubi`：只生成 33 个 `wubi86.ci.<slug>.dict.yaml` 类目词表与构建报告。
- 基础项目结构（三 schema、prism/OpenCC 配置、字表、主表、README/LICENSE）由 `rime-wubi` 仓库维护；组装与发布也在该仓库完成。
- 其它 target 必须显式指定，不进入 v1 验收。

## 物料要求

- UTF-8、LF、一行一词、无 BOM、无空行、无首尾空白。
- 允许字符：汉字（含扩展区）、ASCII 字母数字、`·`、`-`；长度 2–10。
- 全局去重；一个词只归属一个物料类目。
- 73 个类目文件齐全；空文件允许；`planned` 文件必须为空。
- 无来源、编码、频次、权重、原始字形。

## 类目要求

- 物料类目为工程契约，正本在[词模 CiMo](https://github.com/chinese-ci/cimo) `taxonomy`，含类目树、文件、slug、顺序、`planned` 与依据。
- 来源类目只在来源层；不得进入物料或公开契约。
- 类目增删、路径或顺序变化属于契约变更。

## 目标产物要求

- 默认 target 与官方方案同名，可 drop-in；三个 schema 共用主词表。
- 主表 `sort: original`，`columns` 只有 `text` 与 `code`。
- 真实 Rime 部署、按码查词、`wubi_trad` [OpenCC](https://github.com/BYVoid/OpenCC) 通过。
- 包内无来源名与权重。

## 非功能要求

- **确定性**：来源 `order` → `source_id` → 文本行序；类目顺序由 taxonomy 固定。
- **可追溯**：`source_id` 可回查私有来源映射；公开侧只留结论与产物指纹。
- **可替换**：三个工具通过契约连接，不互相 import 运行时私有结构。
- **可扩展**：新来源 = 新生产者；新输入法 = 新 target 适配器。

## 验收口径

- 物料文件集合与条级契约通过。
- 构建跳过率未超阈值；报告无来源名/权重。
- 默认 target 三 schema 可部署、可查词、OpenCC 正常。
- 公开仓库许可/README/NOTICE 齐全。
- 验收记录含输入哈希、产物哈希、工具版本与已知缺口。

## 非目标

- v1 不接入默认 target 之外的输入法产物。
- v1 不提供公开的删除/改类目操作；由来源层策展覆盖处理。
- v1 不承诺来源层的平台总量与平台计数一致。
- 不接收原始平台文件或整份来源语料的公开 PR。
