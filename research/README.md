# 标准与类目调研

本目录保存跨[词修 CiXiu](https://github.com/chinese-ci/cixiu) / [词合 CiHe](https://github.com/chinese-ci/cihe) 的标准调研：

- `中文分类标准调研.md`：GB/T 20093-2022 等分类标准。
- `通用规范汉字表调研.md`：规范字表与增广边界。
- `assets/README.md`：标准原文链接与使用边界。

来源与平台调研留在私有来源层；编码器与目标工具调研放在对应的工具仓库。本目录只放平台无关的标准与类目依据。

标准原文 PDF 受版权保护，仅供内部研究，**不进入 git**（`.gitignore` 已忽略 `*.pdf`）。本目录只保留调研结论与官方链接；需要原文时按 `assets/README.md` 的链接在国家标准全文公开系统查阅。
