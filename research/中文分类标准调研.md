# 中文分类标准调研

研究日期：2026-11-21。范围：中文语境下与「分类 / 类目」相关的国家标准、行业标准与权威分类工具。方法：优先查国家标准全文公开系统（openstd.samr.gov.cn）、全国标准信息公共服务平台（std.samr.gov.cn）、国家统计局、国家图书馆《中图法》官网等一手来源；标准正文无法机读时，用标准元数据与学术转引，并标注置信度。文末来源按 `[S#]` 编号。

置信度标记：

- **已确认**：一手来源直接支持，或标准正文可直接引用。
- **高置信二手**：标准正文未能机读，由标准元数据 + 学术论文 / 标准服务站的转引相互印证。
- **未确认**：推断、口径冲突或只检索到单一二手来源，正式定稿前需复核。

## 结论

1. 现行中文分类标准各自面向不同对象：GB/T 13745 面向学科，GB/T 4754 面向经济活动行业，GB/T 20093 面向新闻与公共信息主题；CLC 与 CCT 面向图书馆文献标引；《汉语主题词表》是叙词表，不是类目表。
2. 没有一部现行国家标准同时覆盖通用日常主题分类；生活、娱乐、地名、网络新词等日常主题，需要在现有标准之上自建类目并做映射。
3. GB/T 20093-2022 的公共信息主题框架最接近通用主题分类，但它面向新闻信息，包含新闻特色类；使用时应裁剪并补充自定义类。
4. 各标准的粒度与组织逻辑差异很大：GB/T 13745 是研究领域（3 级、2,382 个三级学科），GB/T 4754 是生产活动（4 级、1,382 个小类），CLC / CCT 是文献标引（5 万级类目），不能直接互换。

## 2. GB/T 13745《学科分类与代码》

### 2.1 版本与状态（已确认）

- 现行版本是 **GB/T 13745-2009**，推荐性国家标准，状态「现行」。2009-05-06 发布，2009-11-01 实施；全部代替 GB/T 13745-1992。[S1][S2]
- 2009 版之后没有新版换版；有两次修改单：第 1 号修改单（XG1-2012）和第 2 号修改单（XG2-2016）。2025-03-27 复审结论为「继续有效」。[S1][S2]
- 发布单位：国家质量监督检验检疫总局、国家标准化管理委员会；提出单位：中国标准化研究院；归口单位：全国信息分类编码标准化技术委员会（TC353）。[S3]

### 2.2 结构与精确数量（已确认，修改单后的总数未逐条重算）

标准正文第 5.2 条：**5 个门类、62 个一级学科或学科群、676 个二级学科或学科群、2,382 个三级学科**。[S3]

门类名称与代码区间（门类只用于科技统计，不在标准的学科代码表中出现）：

| 门类 | 名称 | 代码区间 |
|---|---|---|
| A | 自然科学 | 110–190 |
| B | 农业科学 | 210–240 |
| C | 医药科学 | 310–360 |
| D | 工程与技术科学 | 410–630 |
| E | 人文与社会科学 | 710–910 |

来源：[S3]。

> 注意：62 / 676 / 2,382 是 2009 年标准正文的口径。两次修改单有局部增删（例如第 1 号修改单删除 6305520 人才学、新增 6305521 人才开发与管理，并在 840 社会学下新增 84072 人才学），因此「当前精确总数」可能略有出入；正式引用时应写「2009 年版正文口径 62 / 676 / 2,382，另有两次修改单」。[S1][S2]

### 2.3 分类逻辑与覆盖范围

标准自己明确说明：

> 「本标准的分类对象是学科，不同于专业和行业。本标准的分类不能代替文献、情报、图书分类及学术上的各种观点。」[S3]

- **日常生活**：没有「日常」「生活服务」「家常菜」「服饰」等位置；这些主题只能散落到社会学、经济学、轻工业等学科下。
- **娱乐 / 游戏**：没有「游戏」类；电子游戏不是学科。娱乐相关内容只能落到「体育科学」「新闻学与传播学」「艺术学」等学科下。
- **地名**：地理学是自然科学下的学科，但不处理行政区划、景点、街道等主题。
- **粒度**：三级学科 2,382 个，学术粒度，适合学科统计与管理；用于通用主题分类过细。

**适用场景**：学科统计、学科管理、科研项目分类；专业领域的二级参考，不宜作为通用主题分类的顶层。

## 3. GB/T 4754《国民经济行业分类》

### 3.1 版本与状态（已确认，修订在途）

- 现行版本是 **GB/T 4754-2017**，推荐性国家标准，状态「现行」。2017-06-30 发布，2017-10-01 实施；文本附 2019 年第 1 号修改单。[S4][S5]
- 2019 年 3 月，国家标准委发布并实施第 1 号修改单，主要调整监察委员会相关行业分类。[S5]
- 修订计划 **20253393-T-410** 已下达（2025-08-06，周期 16 个月），状态「正在审查」，拟全部代替 GB/T 4754-2017；截至 2026-11-21 尚未发布新版。[S7]

- **20 个门类、97 个大类、473 个中类、1,382 个小类**。[S5]

### 3.3 分类逻辑与覆盖范围

它是「经济活动的行业分类」，不是「主题分类」：

- **日常生活**：没有「日常」「家居」「菜谱」「美容」「服饰」等生活类目；这些主题只能落到制造业、批发零售、居民服务等经济活动下。
- **娱乐**：R「文化、体育和娱乐业」覆盖电影、电视、文艺、体育、娱乐，但不覆盖具体作品名、明星、动漫角色等主题。
- **游戏**：没有独立的「游戏」门类；游戏软件 / 数字内容可能落到 I「信息传输、软件和信息技术服务业」，游戏厅等落到 R，分类逻辑是产业活动而非内容主题。
- **地名**：不覆盖行政区划、景点、街道等主题。
- **粒度**：4 级 1,382 个小类，行业粒度；大量小类是生产活动名称。

**适用场景**：行业统计、行业管理、企业 / 产品 / 职业 / 产业术语分类；不宜作为通用主题分类的顶层。

## 4. GB/T 20093《中文新闻信息分类与代码》

### 4.1 版本与状态（已确认）

- 现行版本是 **GB/T 20093-2022**，推荐性国家标准，状态「现行」。2022-10-12 发布并实施；全部代替 GB/T 20093-2013（2013 版曾代替 GB/T 20093-2006）。[S8][S9]
- 发布单位：国家市场监督管理总局、国家标准化管理委员会；归口单位：全国中文新闻信息标准化技术委员会（SAC/TC 352）；起草单位包括新华社、广西日报传媒集团、视觉（中国）、湖南省青苹果数据中心、中科院计算所等。[S10]
- 2022 版相对 2013 版的主要变化：新增类目 1,008 个、更改类目说明 1,205 处、增加交替类目 71 个，并规范部分类目名称、调整部分代码。[S10]

### 4.2 结构与数量（高置信二手）

- 采用线分类与面分类相结合的方法，由**主类表**和**复分表**构成。[S10]
- 主类表从粗到细分 **5 个层级**；**一级类目 24 个，二级类目 367 个**。[S10]
- 类目表包括：表 1 一级类表、表 2 简表（一、二级类目）、表 3 详表（全部类目）；附录 A 总类复分表、附录 B 人物复分表、附录 C 新闻信息体裁表。[S10][S11]
- 编码：主类表代码用两位数字分层；复分表代码与主类表代码通过冒号组配；交替类目用方括号表示。[S10][S11]
- 规范性引用文件包括 GB/T 2260（中国行政区划代码）、GB/T 2659（世界国家 / 地区代码）、GB/T 3304（中国各民族名称代码）。这意味着**地名、国家 / 地区、民族不在主类表中，而由外部代码 / 复分处理**。[S10]

> 2026-11-21 复核：`research/assets/GBT+20093-2022.pdf` 为 **472 页全文**；正文明确「一级类目 24 个，二级类目 367 个」；表 1 已用第 9 页页面图像逐字核对。PDF 文本层为自定义编码，直接抽取会乱码；表 2 / 表 3 在全文 PDF 中可得，逐条提取需 OCR / 解析。

### 4.4 分类逻辑与覆盖范围

这是最接近「公共信息主题」的现行国标，但它的分类对象是新闻信息：

- **日常生活**：部分覆盖。05 社会、劳动；21 服务业、旅游业；35 文化、休闲娱乐；38 医药、卫生；39 体育；31 教育。没有「家常菜」「家居」「美容」「服饰」等生活细类。
- **娱乐**：覆盖较好。35 文化、休闲娱乐；36 文学、艺术；37 传媒；39 体育。电影、电视、音乐、明星、动漫等可落到 35 / 36，具体下位类需查详表。
- **游戏**：没有独立一级类目。电子游戏、网络游戏只能落到 35 文化、休闲娱乐（或 36 文学、艺术）的下位类；具体有没有「游戏」下位类，需查表 3 详表。[S11]
- **地名**：不在主类表。标准用 GB/T 2260、GB/T 2659 等外部代码 / 复分处理行政区划和国家 / 地区；旅游景点可能落到 21 服务业、旅游业。
- **粒度**：24 个一级、367 个二级、5 层，详表约 440 页；一级类目数量偏多，且包含「对外关系」「灾难、事故」「传媒」等新闻特色类，直接照搬会产生大量空类。
- **分类逻辑**：新闻信息主题，同一个主题可能因新闻语境落到不同类；需要稳定的「一主题一主类」规则时，必须做裁剪和映射。

**适用场景**：公共信息主题分类、新闻内容标引、跨机构主题映射；作为通用主题分类的参照框架时，需要裁剪新闻特色类并补自定义类。

## 5. 《中国图书馆分类法》（CLC）

### 5.1 版本、编制者与状态（已确认）

- **不是国家标准**，是我国图书馆界使用最广的大型综合性分类法；英文名 Chinese Library Classification（CLC）。[S13]
- 编制始于 1971 年，先后出版五版；**现行印刷版为第五版，2010 年出版**。由**国家图书馆《中图法》编委会**编制。[S13]
- 第五版在第四版基础上修订；至第五版为**五大部类、二十二个大类、51,881 个类目（包括通用类目）**。[S13]
- 第五版出版后以 **Web 版**持续修订；官方页面称 Web 版包含第五版出版后的所有修订刊物信息，共 180 多个类目的更新。[S15]
- 截至 2026-11-21，**未检索到第六版正式出版**；官方渠道仍是「第五版 + Web 版实时更新」。这是「未检索到」的结论，不是官方声明「永远不会出第六版」。[S13][S15]

### 5.3 分类逻辑与覆盖范围

CLC 的组织逻辑是「图书馆排架 / 检索」，不是「主题分类」：

- **日常生活**：没有「生活」大类；家常菜、家居、服饰、美容等散落在 TS（轻工业 / 生活服务）、R（医药卫生）、F（经济）等类目下，普通用户无法按 22 大类直觉定位。
- **娱乐**：G（文化、科学、教育、体育）、J（艺术）覆盖，但电影、电视、动漫、游戏、明星等没有统一的现代娱乐类目；电子游戏在 CLC 中没有独立大类。
- **游戏**：没有「游戏」大类；传统棋牌、体育游戏可能落到 G8，电子游戏没有稳定位置。
- **地名**：K9 地理、K 历史 / 地理；行政区划、景点、街道不是独立大类。
- **粒度**：51,881 个类目，远比通用主题分类细；类目按学科 / 文献类型组织，不是按日常主题组织。
- **授权**：CLC 是商业出版物，未发现开放许可；分类号作为标识被广泛使用，但整表复制 / 再分发需要授权。

**适用场景**：图书馆文献标引、书目检索、跨表参考；不宜作为通用主题分类的顶层。

## 6. 《汉语主题词表》与 GB/T 13190 叙词表标准

### 6.1 《汉语主题词表》（已确认，部分数字为二手）

- 我国第一部大型综合性**叙词表**（不是分类法）。1980 年由科学技术文献出版社出版，中国科学技术情报研究所（现中国科学技术信息研究所）与北京图书馆组织编制；3 卷 10 册，共 108,568 个词（91,158 个正式主题词 + 17,410 个非正式主题词）。1985 年获国家科学技术进步奖二等奖。[S17]
- 1991 年出版《汉语主题词表（自然科学增订本）》，主体表约 8.1 万词（二手统计）。[S17]
- 2009 年起中国科学技术信息研究所主持重编，规划工程技术、自然科学、生命科学、社会科学四卷；工程技术卷 2014 年出版（13 分册，19.6 万优选词 + 16.4 万非优选词），自然科学卷 2018 年 5 月出版（5 分册，约 12.4 万专业术语，6.5 万优选词 + 5.9 万非优选词）。[S17]
- 它是**主题词表**：按字顺和范畴组织，用等同、属分、相关关系连接词，不是「一级类目 / 二级类目」式的主题分类表。

### 6.2 GB/T 13190 叙词表标准（已确认）

- **GB/T 13190-1991《汉语叙词表编制规则》已废止**，被 **GB/T 13190.1-2015** 全部代替。[S18]
- **GB/T 13190.1-2015**《信息与文献 叙词表及与其他词表的互操作 第 1 部分：用于信息检索的叙词表》：推荐性国标，现行；2015-05-15 发布，2015-12-01 实施；修改采用 ISO 25964-1:2011；2025-05-30 复审结论「继续有效」；全部代替 GB/T 13190-1991 和 GB/T 15417-1994。[S18]
- **GB/T 13190.2-2018**《信息与文献 叙词表及与其他词表的互操作 第 2 部分：与其他词表的互操作》：推荐性国标，现行；2018-06-07 发布，2019-01-01 实施；修改采用 ISO 25964-2:2013。[S19]
- 这两个标准规定叙词表的编制、显示、互操作和映射，**不规定主题类目表**；适合作为自建受控词表 / 同义词环 / 层级关系的方法论依据。

### 6.3 分类逻辑与覆盖范围

不是类目表，是**词表编制方法**：

- 可用来定义同义词 / 近义词、入口词、属分关系、相关关系，以及和外部词表（如 CLC、CCT）的映射。
- 但它不回答「分几类、每类叫什么」。
- 《汉语主题词表》本身是学术 / 文献主题词，覆盖自然科学、工程技术、社会科学，生活口语和网络新词覆盖弱。

## 7. 《中国分类主题词表》（CCT）

### 7.1 名称与版本（已确认）

- 正式名称是 **《中国分类主题词表》**（Chinese Classified Thesaurus，CCT），不是《中文分类主题词表》。未检索到以「中文分类主题词表」为名的独立标准或工具书。[S16]
- 由**国家图书馆《中国图书馆分类法》编辑委员会**主持编制，1994 年第一版；2005 年 9 月第二版；**2017 年 4 月第三版**，共 2 卷 8 个分册。第三版以《中图法》第五版为基础修订。[S16]
- Web 版 2010-03-17 正式发布，2014 年随《中图法》第五版更新为 2.1 版；官方页面称至 2021 年 9 月共进行六次更新，新增入口词近 1 万条，类目也有增删改。[S16]
- 截至 2026-11-21，**未检索到第四版**；第三版印刷版仍是最新印刷版，Web / 机读数据持续更新。[S16]

### 7.2 结构与规模（已确认）

CCT 是「分类法—叙词表对照索引式」的分类主题一体化检索语言，由两卷组成：

- **第一卷：分类号—主题词对应表**。按《中图法》类目顺序，列出每个类目对应的叙词款目、注释、先组式标题；用于分类标引，以及从分类途径查主题词。[S16]
- **第二卷：主题词—分类号对应表**。按主题词 / 主题词串字顺排列，列出对应的分类号；用于主题标引，以及从主题查分类号。[S16]

规模（第三版）：

- 分类法类目 **51,873 条**
- 优选主题词 **120,818 条**
- 非优选主题词（入口词）**46,434 条**
- 主题概念短语（入口短语）**66,373 条**，指向主题词组配式 **61,892 条**。[S16]

关系：

- 它是在《中图法》和《汉语主题词表》基础上编制的分类—主题一体化工具。[S16]
- 官方页面明确：第三版「起到《汉语主题词表》第 3 次修订版的作用」。[S16]
- 因此，CCT 同时依赖 CLC 的分类骨架和《汉语主题词表》的叙词关系；它不是一套独立的、面向大众的主题分类。

### 7.3 分类逻辑与覆盖范围

不适合作为通用主题分类的顶层，理由与 CLC 类似但更强：

- **粒度极细**：51,873 个类目 + 12 万优选词 + 4.6 万入口词 + 6.6 万入口短语；这是文献标引工具。
- **分类逻辑是文献主题**：按《中图法》类目组织，普通用户无法从 22 大类 / 5 大部类直觉定位「火锅」「奶茶」「王者荣耀」等主题。
- **生活 / 娱乐 / 游戏 / 地名**：与 CLC 一样，生活主题分散，游戏无独立类，地名不是主类。
- **可用之处**：给领域主题补充同义词、入口词、上下位关系，或把自有类目映射到 CLC；不宜作为顶层类目表。
